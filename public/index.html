      Zo snel gaat het

      Eén prompt. Een paar minuten. Live.

      Je hoeft geen server te regelen, niets te installeren en geen code te schrijven. Je vertelt wat je wilt, de AI-assistent doet de rest. Daarna heb je een link die je meteen kunt delen.

      Waarvoor

      Waar is het Education Vibe Cluster voor?

      Hier is het voor

      • Goede ideeën delen met collega’s. Maak je idee beschikbaar, zodat je collega’s het echt kunnen gebruiken.
      • Een schets of proof of concept laten zien aan een klant. Een proof of concept is een eerste werkende versie van een idee. De klant klikt er zelf doorheen, in plaats van naar plaatjes te kijken.

      Hier is het niet voor

      Werken met productiedata. Productiedata zijn echte gegevens uit de praktijk, zoals die van leerlingen, ouders, klanten of medewerkers. Die mogen niet op het Education Vibe Cluster.

      Daarvoor hebben we het pilot cluster. Wil je daar toegang toe? Neem contact op met de head of innovation.

      Inspiratie

      Ideeën die je zo live zet

      Drie voorbeeldprompts. Neem ze over, of begin met je eigen idee.

      • Voor je collega’s

        Roosters delen

        ‘Maak een pagina waar docenten roosters kunnen delen. Zet het live.’

      • Voor een klant

        Een klikbare klantdemo

        ‘Maak een klikbare demo van een dashboard voor schoolleiders, om aan een klant te laten zien.’

      • Voor je team

        Een rekenhulp

        ‘Maak een rekenhulp die uitrekent hoeveel lesuren een klas per vak krijgt.’

      Hoe het werkt

      In drie stappen aan de slag

      1. Activeer je code

        Je kreeg een invitecode van een collega die al meedoet. Vul hem in, samen met je naam en e-mailadres.

      2. De beheerders zetten je toegang klaar

        Zij maken je account aan op het cluster. Je krijgt een e-mail zodra je aan de slag kunt.

      3. Geef drie codes door

        Je krijgt meteen drie nieuwe codes. Geef ze aan collega’s die er volgens jou iets aan hebben. Zo groeit de groep via mensen die elkaar kennen.

      Vragen

      Veelgestelde vragen

      Ik heb geen code. Hoe kom ik eraan?

      Vraag een collega die al toegang heeft. Iedereen die meedoet, krijgt drie codes om door te geven.

      Mijn code werkt niet. Wat nu?

      Kijk of je de code goed hebt overgenomen. Hoofdletters, spaties en streepjes maken niet uit.

      Werkt hij nog steeds niet? Dan is hij misschien al gebruikt. Vraag de collega die hem gaf om een andere code.

      Wanneer kan ik aan de slag?

      De beheerders zetten je toegang klaar nadat je je code hebt ingevuld. Je krijgt een e-mail zodra het zover is.

      Mag ik echte gegevens van leerlingen of klanten gebruiken?

      Nee. Productiedata horen niet op het Education Vibe Cluster. Daarvoor hebben we het pilot cluster.

      Voor toegang daartoe mail je de head of innovation (bob.reijnders@topicus.nl).

      Ik ben mijn drie codes kwijt.

      Vul je eigen code en je e-mailadres opnieuw in. Je ziet dan dezelfde drie codes weer.

      Begrippen

      Prompt
      Een opdracht in gewone taal. Bijvoorbeeld: ‘Maak een pagina waar docenten roosters kunnen delen. Zet het live.’
      AI-assistent
      Een programma met kunstmatige intelligentie (AI). Het schrijft de code voor je.
      Vibe coding
      Software maken door te beschrijven wat je wilt, in plaats van zelf code te schrijven.

      Een groep servers die samenwerkt. Hier draait jouw idee, met een eigen webadres.
      Invitecode
      Een code waarmee je toegang aanvraagt. Hij werkt één keer. Ook wel activatiecode genoemd.
      Proof of concept
      Een eerste werkende versie van een idee. Je laat ermee zien dat het kan.
      Productiedata
      Echte gegevens uit de praktijk, zoals die van leerlingen, ouders, klanten of medewerkers.
      Pilot cluster
      Een apart cluster voor werk met productiedata. Toegang vraag je aan bij de head of innovation.
